# Architecture

Ce dépôt illustre un MVP pour la plateforme Aspar Group.

- **Backend** : Airtable pour le stockage des données.
- **Frontend** : Softr connecté à Airtable pour l'interface.
- **Scripts** : voir `backend/` pour des exemples d'accès à l'API Airtable.

Les fichiers CSV ou JSON peuvent être placés dans `data/` pour des imports.
