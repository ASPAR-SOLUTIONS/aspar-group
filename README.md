# aspar-group# Aspar Group Platform – MVP

Plateforme de franchises citoyennes en Tunisie.

## Stack MVP
- Backend données : Airtable (import CSV)
- Frontend : Softr (connecté à Airtable)
- Documentation et analyses : voir /docs

## Organisation du dépôt
- `/docs` : analyses, specs, mockups
- `/data` : exemples de données (CSV, JSON)
- `/backend` : scripts Python pour l'API Airtable
- `/frontend` : maquettes ou pages statiques
