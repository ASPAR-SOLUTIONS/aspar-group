# Backend

Simple utilities to interact with Airtable.

## Requirements

- Python 3.8+
- [pyairtable](https://github.com/gtalarico/pyairtable)

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Example usage

Set the `AIRTABLE_API_KEY` and `AIRTABLE_BASE_ID` environment variables and run:

```bash
python airtable_client.py
```
